
# Maya Native Mesh Reducer (智能减面工具)

**Native Mesh Reducer** 是一款专为 Maya 设计的高级模型减面与拓扑处理插件。它在 Maya 原生 `polyReduce` 算法的基础上，封装了强大的自动化流程，包括**蒙皮无损保护**、**射线防穿插内部面清理**、**实时法线预览修复**，以及基于 `OpenMaya (OM2)` 的**极速硬边/拓扑计算**。

工具采用吸附式 Workspace UI 完美贴边，操作直观，是游戏资产优化、LOD 生成和技术美术 (TA) 日常管线的得力助手。

## ✨ 核心特性 (Features)

* 🚀 **OM2 极速底层计算**：拓扑选择（硬边/硬边点）采用纯 `Maya API 2.0 (C++)` 内存级别计算，无惧数百万面级高模，瞬间完成筛选。
* 🛡️ **蒙皮权重完美继承**：支持“保留蒙皮”选项，在生成 LOD 时自动备份并精准重绑权重，免去重复刷权重的烦恼。
* 🔍 **智能内部面剔除 (Raycast + Texel)**：独创算法结合 UV 密度（Texel Density）与空间射线追踪，精准识别并删除被遮挡的内部面或隐藏结构，杜绝误删表面。
* ✨ **无损法线与平滑修复**：独创拖拽式“软硬边”实时预览功能，支持在确认前撤销历史，不产生多余垃圾节点。
* 🏷️ **LOD 组智能自动化**：一键识别模型组，通过正则提取核心命名，并按三角面数严格降序自动重命名（如 `Asset_LOD0`, `Asset_LOD1`...）。
* 🧩 **智能拆分与特征保护**：支持按纹理（UV）边界断开拓扑，提供针对边界、UV、颜色、材质、硬边的权重保护滑块。

## 🛠️ 安装与运行 (Installation & Usage)

1. 将 `MeshReducer.py` 文件放入您的 Maya 脚本目录，或者直接将代码拖拽至 Maya 的 **Script Editor (脚本编辑器)** 的 Python 选项卡中。
2. 选中全部代码并执行，或将其保存为工具架 (Shelf) 按钮，使用以下 Python 代码启动：

```python
import MeshReducer
MeshReducer.show_ui()

```

*(工具面板将以 Workspace 窗口形式启动，您可以将其吸附在 Channel Box 或 Attribute Editor 旁)*

## 📖 界面模块说明 (Modules Breakdown)

### 1. 减面执行 (基于 Maya 底层)

核心减面引擎，提供高度定制化的减面策略：

* **模式选择**：支持仅针对【选中的网格】或自动提取场景内【所有蒙皮网格】。
* **减面方式**：可通过【保留百分比】或精确设定【目标三角数】进行控制。
* **对称与蒙皮**：支持自动/平面虚拟对称；勾选【保留蒙皮】即可自动烘焙变形器。
* **删内部面**：启用后，工具会利用 UV Shell 阈值与射线投射，在减面前预先剔除不可见的内部废面。
* **Shell 定位调试**：提供强大的低 UV 密度面排查工具，支持输入 Shell ID 单独定位选区。

### 2. 高级特征保护 (Advanced Protection)

为 Maya 原生减面算法提供权重干预，滑块范围 `0.0` (忽略) ~ `1.0` (完全锁定)。

* 支持保护的特征：**外边界 (Border)**、**UV 边界 (Map)**、**颜色边界 (Color)**、**材质边界 (Mat)**、**硬边 (Hard)**、**折痕边 (Crease)**。

### 3. 后期修复 (实时无损预览)

专为拓扑修改后的法线和平滑组修复打造：

* **二面角法线预览**：拖拽滑块即可**实时预览**软硬边效果。点击【还原】无痕取消历史，点击【确认】即可固化历史并烘焙法线。
* **拆出纹理边界**：选中边或面，一键沿 UV 缝隙物理断开网格拓扑。
* **极速选择硬边线 / 硬边点**：利用 OM2 API 过滤计算，智能排除因拆分 UV 边界而产生的重合顶点干扰，精准选中真正的硬边与折角顶点。

### 4. LOD 组智能重命名

针对游戏引擎导入规范设计的批量重命名工具：

* 选中一个或多个包含 Mesh 的 `Transform/Group` 节点。
* 工具会智能剥离无关后缀（如 `_high`, `_mat`, `_v1`），提取出核心命名。
* 自动计算组内所有子网格的三角面数，按面数从高到低依次重命名为 `_LOD0`, `_LOD1`, `_LOD2` 等。

### 5. 执行日志 (Console Log)

内置独立日志窗口，实时打印减面比率、内部面剔除统计、剔除失败警告及耗时信息，确保全流程数据可追溯。

## ⚙️ 技术细节 (Tech Specs)

* **运行环境**: 兼容 Maya 2018+ (支持 Python 2.7 与 Python 3.x)。
* **底层 API**: 大量依赖 `maya.api.OpenMaya` (OM2) 实现网格空间运算（如点法线判断、UV面积极速求和、射线碰撞检测 `closestIntersection`）。
* **UI 框架**: 采用原生 `maya.cmds` 配合 `workspaceControl`，确保跨版本界面一致性且无额外依赖。
